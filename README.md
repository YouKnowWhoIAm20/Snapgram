## <a name="overview">🤖 Overview</a>

Explore an easy-to-use social platform packed with features. Users can seamlessly browse posts, enjoy strong security, and experience efficient data retrieval using React Query.

## <a name="technologies">⚙️ Technologies Used</a>

- React.js
- Appwrite (BaaS)
- React Query (Tanstack)
- TypeScript
- Tailwind CSS

## <a name="key-features">🔋 Key Features</a>

- **Secure Authentication**: Ensures user data privacy with a reliable authentication system.
- **Post Exploration**: A homepage feature for discovering content, including highlighted posts from top creators.
- **Engagement Options**: Allows users to like and save posts, along with managing them easily.
- **Detailed Post View**: A dedicated page showing post details and related content for an immersive experience.
- **User Profiles**: Users can edit and manage their profiles, including viewing liked posts.
- **Create & Edit Posts**: A seamless post creation page with drag-and-drop functionality.
- **Responsive UI**: A mobile-first design with a dynamic bottom navigation bar.
- **React Query Integration**: Optimizes data fetching and caching for improved performance.
- **Backend as a Service (BaaS)**: Leverages Appwrite for backend services like authentication, database, and file storage.
